# 唐金铜 · 平面视觉设计师作品集

基于 **React + Vite** 的单页作品集网站，PC 端优先（版心 1680px），完整翻页滚动（scroll-snap），黑金科技风。

## 运行

```bash
npm install
npm run dev      # 本地开发 http://localhost:5173
npm run build    # 产物输出到 dist/
npm run preview  # 本地预览构建产物
```

## 目录结构

```
tangjintong-portfolio/
├── public/
│   ├── portrait.png          # 个人照片（已抠白底）
│   └── works/                # 作品图片（放这里替换）
│       ├── 海报1.png
│       └── ...               # 15 幅作品
└── src/
    ├── data/content.js       # ★ 所有文案 / 作品 / 技能 / 联系方式的唯一数据源
    ├── index.css             # 全局设计系统（颜色、字体、翻页骨架）
    ├── sections.css          # 各模块样式
    ├── App.jsx               # 页面组装 + 全局入场动画
    ├── hooks/useInView.js    # 视口检测 / 数字滚动
    └── components/           # Navbar / Hero / About / Works / Skills / Footer / DotNav / HeroCanvas
```

## 页内编辑（无需改代码）

打开网站后，点击导航栏右侧 **「✎ 编辑」** 进入编辑模式：

- **改文字**：**页面上所有内容文字均可直接修改**——顶部导航（含英文标签）、Logo、Hero 大标题/眉标/按钮/SCROLL/背景大字、个人经历全段（介绍、教育、实习、数据后缀）、作品区标题与筛选分类名、每张作品卡片的标题/年份/标签/设计说明（≤200 字卡片说明在卡片下方直接改；灯箱里同一条文字也同步）、灯箱内标题/标签/年份/说明、个人优势三栏标题与英文标签、页尾 CTA/按钮/版权/「BACK TO TOP」、IP 气泡与 LIVE 标签、右侧圆点导航文字，全部金色虚线框内直接点击修改
- **作品分类**：作品卡片下方的分类下拉框可直接改分类；分类名（「品牌设计」等）点击筛选按钮上的文字即可改，下拉与筛选按钮文字联动
- **换图片**：点击作品图 / IP 形象 / 证件照，选择本地图片即时替换（单张 ≤ 2.5MB）
- **保存修改**：底部工具栏「保存修改」——写入浏览器本地（localStorage + IndexedDB），刷新后仍然生效
- **重置默认**：清除全部页内修改，恢复为 `content.js` 默认内容
- Esc 键或「退出编辑」关闭编辑模式

> 说明：页内编辑是浏览器本地的个性化覆盖，换电脑/清缓存后不保留；需要固定进源码时，改 `src/data/content.js` 并把替换图片放入 `public/` 即可。
> 编辑模式下链接/按钮暂停跳转，点击文字优先进入编辑；装饰符号（箭头、编号、圆点）与编辑工具栏按钮本身不在编辑范围。

## 如何替换内容

**全部内容都集中在 `src/data/content.js`，改这一个文件即可。**

| 想改什么 | 改哪里 |
|---|---|
| 姓名 / 职业 / 简介 / 数据 | `profile` |
| 教育背景 | `education` |
| 三段实习经历 | `experiences` |
| 作品卡片 | `works` 数组 |
| 优势卡片 / 能力值 / 工具 | `advantages` / `designSkills` / `softwareSkills` / `aiTools` |
| 联系方式 | `contacts` |
| 导航栏目 | `navLinks` |
| 界面文案（导航英文、章节标题、按钮、水印、页脚等全部静态文字） | `ui` 字典 |

### 替换作品图

1. 把新图片放入 `public/works/`（建议 3:4 竖图，如 900×1200）；
2. 在 `content.js` 的 `works` 数组中新增/修改一项：

```js
{
  id: 'my-project',
  file: 'works/你的图片.png',   // 相对 public 的路径
  title: '项目名称',
  category: 'brand',           // brand 品牌 | poster 海报 | ui UI | illustration 插画
  tag: '品牌设计 / 包装设计',
  year: '2026',
  desc: '一句话项目说明，灯箱里展示',
  note: '200 字以内的设计说明，直接展示在作品卡片图片下方（也显示在灯箱中）',
},
```

### 替换个人照片

把新照片命名为 `portrait.png` 放入 `public/` 覆盖即可（深色背景图建议直接替换；白底证件照可用 PS 抠图后替换）。

### IP 形象

个人经历屏的证件照可由 IP 形象替代，并支持真动态效果（默认已启用：`ip/ip-a.jpg` + 循环挥手视频 `videos/ip-mascot.mp4`）。更换方向：把新形象图放进 `public/ip/`，修改 `content.js` 中 `profile.ipMascot`；`profile.ipMascotVideo` 留空则回退为形象图 + 浮动动画，两者都留空则回退显示证件照。

**形象互动**（非编辑模式下）：鼠标移动时形象轻微视差跟随 + 3D 倾斜；悬停时金色高亮并浮现「戳我一下」气泡；点击形象触发弹跳反应 + 金色光环扩散。编辑模式下互动自动停用（点击留给换图）。

### 配置 Hero 视频背景

视频文件放在 `public/videos/hero.mp4`（当前为 AI 生成的黑金光粒子循环背景，约 1MB）。如需更换：把新视频命名为 `hero.mp4` 覆盖 `public/videos/` 下文件即可；也可以在 `content.js` 的 `profile.heroVideo` 中填入任意可播放的视频 URL（留空则回退为内置的金色粒子 Canvas 动画）。

## 页面结构（5 屏翻页）

1. **首页 Hero** — 动态背景 / 大标题 / 导航栏
2. **个人经历** — 照片 / 介绍 / 教育 / 三段实习时间线 / 底部项目数据
3. **项目作品** — 3:4 竖版横向滚动作品墙：鼠标滚轮在屏内任意位置滚动即左右滑动（无需点按钮），也可按住拖拽；+ 分类筛选 + 点击图片灯箱放大 + 卡片下方 200 字内设计说明
4. **个人优势** — 4 张优势卡 + 能力条 / 软件环 / AIGC 工具可视化
5. **联系我** — 合作 CTA + 电话 / 邮箱 / 坐标 + 页脚

右侧圆点导航可一键翻页；作品区横向滚动到最右后继续滚动自动进入下一屏（最左端向上滚回上一屏）。
